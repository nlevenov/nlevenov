### Security and Infrastructure Portfolio

**SOC Alert Prioritizer**
Automated threat triage engine engineered for enterprise Security Operations Centers. Ingests raw event data from SIEM, IDS, and EDR sources via high-throughput FastAPI architecture and utilizes classification models to automate the prioritization of critical alerts.

**IoT Edge Security Platform**
Real-time network traffic analysis and anomaly detection system for edge computing devices. Utilizes Scapy for deep packet inspection and maps normal communication baselines to automatically flag unauthorized network activity, outbound tunneling, and reconnaissance attempts.
